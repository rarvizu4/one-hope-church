# One Hope Church Website

Custom bilingual website for One Hope Church / Iglesia Una Esperanza.

## Publishing the website

The site's HTML, CSS, JavaScript, church photos, and videos must be copied into the root of this repository (the top level, with `index.html` directly beside this README).

After pushing the files, make the repository **Public** in **Settings → General**, then enable **Settings → Pages → Deploy from a branch → main / (root)**.

The website is **not yet live** until these steps are completed.
